# Platform marks

Each `.path` file is the SVG path data (on a 24-unit square) of a platform's mark, taken from
[Simple Icons](https://simpleicons.org), whose files are CC0. `src/logo.rs` draws them.

The marks are trademarks of their owners. The app shows one only to say which platform a provider is
(nominative use); it claims no affiliation or endorsement.
